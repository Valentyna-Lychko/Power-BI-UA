# Power-BI-UA
Репозиторій, присвячений проєктам Power BI: дашборди, звіти та аналітика для демонстрації роботи з даними, їхньої візуалізації та аналізу.

# Power BI: Аналітичні дашборди та звіти

## Огляд репозиторію

Цей репозиторій містить проєкти, створені в Power BI, для демонстрації роботи з даними, їхньої візуалізації та аналізу. Він включає:

1. **Аналітичні проєкти** – дашборди з повним циклом аналізу даних та висновками.  
2. **Візуалізації та звіти** – роботи, що демонструють різні техніки роботи в Power BI.  
3. **Power BI у моїх інших проєктах** – посилання на аналітичні роботи, розміщені в окремих репозиторіях.

---

## 1. Аналітичні проєкти

- **Pizza Sales Analysis**  
  Дашборд для аналізу продажів піци: ключові показники, замовлення за категоріями, часова активність тощо.  
  [Детальний опис](https://github.com/Valentyna-Lychko/Power-BI-UA/blob/main/Analytical-projects/README.md)

---

## 2. Візуалізації та звіти

Роботи, що базуються на навчальних матеріалах, демонструючи техніки створення візуалізацій у Power BI.  
[Переглянути роботи](https://github.com/Valentyna-Lychko/Power-BI-UA/blob/main/Visualizations-and-reports/README.md)

## 3. Power BI у моїх інших проєктах

  Аналіз продажів супермаркету з інтеграцією API для автоматичного отримання курсів валют.

## Матеріали репозиторію
